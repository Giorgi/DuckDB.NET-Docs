# DuckDB.NET 1.4

This page lists the changes in DuckDB.NET 1.4 releases, newest first. For other versions, see [Release Notes](../release-notes.md).

## 1.4.4

Released 2026-02-03. Built on DuckDB v1.4.4.

- Added `DuckDBMappedAppender`, a type-safe way to bulk load data. See [Mapped Appender](../mapped-appender.md).

## 1.4.3

Released 2025-12-11. Built on DuckDB v1.4.3.

- Added support for infinite (±infinity) dates and timestamps. Thanks to @rynoV for the pull request.
- Improved handling of aborted transactions. Thanks to @rynoV for the pull request.
- Fixed decimal parameter handling in prepared statements. Thanks to @rynoV for the pull request.

## 1.4.1

Released 2025-10-13. Built on DuckDB v1.4.1.

- Improved support for parameter binding in parameterized statements.
