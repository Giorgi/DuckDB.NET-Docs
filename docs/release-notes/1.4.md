# DuckDB.NET 1.4

This page lists the changes in DuckDB.NET 1.4 releases, newest first. For other versions, see [Release Notes](../release-notes.md).

## 1.4.4

Released 2026-02-03 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.4.4), [changes since 1.4.3](https://github.com/Giorgi/DuckDB.NET/compare/368787cbc938...597b02fd1155)). Built on DuckDB [v1.4.4](https://github.com/duckdb/duckdb/releases/tag/v1.4.4).

- Added `DuckDBMappedAppender`, a type-safe way to bulk load data. See [Mapped Appender](../mapped-appender.md).

## 1.4.3

Released 2025-12-11 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.4.3), [changes since 1.4.1](https://github.com/Giorgi/DuckDB.NET/compare/c5c7ff890c4f...368787cbc938)). Built on DuckDB [v1.4.3](https://github.com/duckdb/duckdb/releases/tag/v1.4.3).

- Added support for infinite (±infinity) dates and timestamps. Thanks to [@rynoV](https://github.com/rynoV) for the pull request.
- Improved handling of aborted transactions. Thanks to [@rynoV](https://github.com/rynoV) for the pull request.
- Fixed decimal parameter handling in prepared statements. Thanks to [@rynoV](https://github.com/rynoV) for the pull request.

## 1.4.1

Released 2025-10-13 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.4.1), [changes since 1.3.2](https://github.com/Giorgi/DuckDB.NET/compare/cab71b0ad887...c5c7ff890c4f)). Built on DuckDB [v1.4.1](https://github.com/duckdb/duckdb/releases/tag/v1.4.1).

- Improved support for parameter binding in parameterized statements.
