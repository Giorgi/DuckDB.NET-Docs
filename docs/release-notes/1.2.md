# DuckDB.NET 1.2

This page lists the changes in DuckDB.NET 1.2 releases, newest first. For other versions, see [Release Notes](../release-notes.md).

## 1.2.1

Released 2025-03-05 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.2.1), [changes since 1.2.0](https://github.com/Giorgi/DuckDB.NET/compare/79857ba6562f...cfaaa845afe4)). Built on DuckDB [v1.2.1](https://github.com/duckdb/duckdb/releases/tag/v1.2.1).

- Fixed binding statements that use explicit casts.

## 1.2.0

Released 2025-02-06 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.2.0), [changes since 1.1.3](https://github.com/Giorgi/DuckDB.NET/compare/1c8cc9b8f790...79857ba6562f)). Built on DuckDB [v1.2.0](https://github.com/duckdb/duckdb/releases/tag/v1.2.0).

- Added support for binding nested List and Array values.
- Added support for binding a List with null values.
- Added support for inserting TIMESTAMP_MS, TIMESTAMP_NS and TIMESTAMP_S values.
