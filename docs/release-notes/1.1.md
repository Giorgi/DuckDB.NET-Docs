# DuckDB.NET 1.1

This page lists the changes in DuckDB.NET 1.1 releases, newest first. For other versions, see [Release Notes](../release-notes.md).

## 1.1.3

Released 2024-11-07 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.1.3), [changes since 1.1.2.1](https://github.com/Giorgi/DuckDB.NET/compare/a2bb658e370c...1c8cc9b8f790)). Built on DuckDB [v1.1.3](https://github.com/duckdb/duckdb/releases/tag/v1.1.3).

- Added support for creating user-defined table-valued functions.
- Added support for passing LIST parameters.

## 1.1.2.1

Released 2024-10-21 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.1.2.1), [changes since 1.1.1](https://github.com/Giorgi/DuckDB.NET/compare/4f882277be75...a2bb658e370c)). Built on DuckDB [v1.1.2](https://github.com/duckdb/duckdb/releases/tag/v1.1.2).

It replaces version 1.1.2, which is unlisted on NuGet and bundles DuckDB v1.1.1.

## 1.1.1

Released 2024-09-24 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.1.1), [changes since 1.1.0.1](https://github.com/Giorgi/DuckDB.NET/compare/67dc268a8e8d...4f882277be75)). Built on DuckDB [v1.1.1](https://github.com/duckdb/duckdb/releases/tag/v1.1.1).

## 1.1.0.1

Released 2024-09-09 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.1.0.1), [changes since 1.0.2](https://github.com/Giorgi/DuckDB.NET/compare/b7d838821d6a...67dc268a8e8d)). Built on DuckDB [v1.1.0](https://github.com/duckdb/duckdb/releases/tag/v1.1.0).

It replaces version 1.1.0, which is unlisted on NuGet.

- Added support for creating user-defined scalar functions.
- Added support for the VARINT type.
- Added support for writing to Enum columns with the managed appender.
