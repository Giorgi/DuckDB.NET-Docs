# DuckDB.NET 1.1

This page lists the changes in DuckDB.NET 1.1 releases, newest first. For other versions, see [Release Notes](../release-notes.md).

## 1.1.3

Released 2024-11-07. Built on DuckDB v1.1.3.

- Added support for creating user-defined table-valued functions.
- Added support for passing LIST parameters.

## 1.1.2.1

Released 2024-10-21. Built on DuckDB v1.1.2.

It replaces version 1.1.2, which is unlisted on NuGet and bundles DuckDB v1.1.1.

## 1.1.1

Released 2024-09-24. Built on DuckDB v1.1.1.

## 1.1.0.1

Released 2024-09-09. Built on DuckDB v1.1.0. It replaces version 1.1.0, which is unlisted on NuGet.

- Added support for creating user-defined scalar functions.
- Added support for the VARINT type.
- Added support for writing to Enum columns with the managed appender.
