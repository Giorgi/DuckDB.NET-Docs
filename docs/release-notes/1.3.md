# DuckDB.NET 1.3

This page lists the changes in DuckDB.NET 1.3 releases, newest first. For other versions, see [Release Notes](../release-notes.md).

## 1.3.2

Released 2025-07-08 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.3.2), [changes since 1.3.0](https://github.com/Giorgi/DuckDB.NET/compare/dae272142e72...cab71b0ad887)). Built on DuckDB [v1.3.2](https://github.com/duckdb/duckdb/releases/tag/v1.3.2).

- Fixed a memory leak in query execution.

## 1.3.0

Released 2025-06-03 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/1.3.0), [changes since 1.2.1](https://github.com/Giorgi/DuckDB.NET/compare/cfaaa845afe4...dae272142e72)). Built on DuckDB [v1.3.0](https://github.com/duckdb/duckdb/releases/tag/v1.3.0).

- Added support for parameterless table-valued functions.
