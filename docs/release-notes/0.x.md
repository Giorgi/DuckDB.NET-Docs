# DuckDB.NET 0.x

This page lists the changes in DuckDB.NET releases before 1.0, newest first. For other versions, see [Release Notes](../release-notes.md).

## 0.10.3

Released 2024-05-22 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.10.3), [changes since 0.10.2](https://github.com/Giorgi/DuckDB.NET/compare/71a2908767a5...c9fceec44943)). Built on DuckDB [v0.10.3](https://github.com/duckdb/duckdb/releases/tag/v0.10.3).

- Added support for writing `decimal`, `Guid` and `DateTimeOffset` values with the managed appender.
- Implemented `DuckDBConnection.GetSchema`. Thanks to @hazzik.

## 0.10.2

Released 2024-04-21 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.10.2), [changes since 0.10.1](https://github.com/Giorgi/DuckDB.NET/compare/9dcc10e2b627...71a2908767a5)). Built on DuckDB [v0.10.2](https://github.com/duckdb/duckdb/releases/tag/v0.10.2).

## 0.10.1

Released 2024-03-18 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.10.1), [changes since 0.9.2](https://github.com/Giorgi/DuckDB.NET/compare/bfe2e593be2e...9dcc10e2b627)). Built on DuckDB [v0.10.1](https://github.com/duckdb/duckdb/releases/tag/v0.10.1).

- Added support for reading TIMETZ values.
- Added support for reading ARRAY values.

The `.Full` packages also have versions 0.10.1.1 and 0.10.1.2, with the same release notes.

## 0.9.2

Released 2023-11-14 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.9.2), [changes since 0.9.1](https://github.com/Giorgi/DuckDB.NET/compare/f86afaa4ca79...bfe2e593be2e)). Built on DuckDB [v0.9.2](https://github.com/duckdb/duckdb/releases/tag/v0.9.2).

- Added support for reading Struct types.

## 0.9.1

Released 2023-10-13 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.9.1), [changes since 0.9.0.3](https://github.com/Giorgi/DuckDB.NET/compare/d73ab1a5ac96...f86afaa4ca79)). Built on DuckDB [v0.9.1](https://github.com/duckdb/duckdb/releases/tag/v0.9.1).

- Added support for reading nested List types.

## 0.9.0.3

Released 2023-10-04 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.9.0.3), [changes since 0.9.0](https://github.com/Giorgi/DuckDB.NET/compare/05246de845ac...d73ab1a5ac96)). Built on DuckDB [v0.9.0](https://github.com/duckdb/duckdb/releases/tag/v0.9.0).

- Added support for reading Enum types.

## 0.9.0

Released 2023-10-02 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.9.0), [changes since 0.8.1](https://github.com/Giorgi/DuckDB.NET/compare/e72e27150f95...05246de845ac)). Built on DuckDB [v0.9.0](https://github.com/duckdb/duckdb/releases/tag/v0.9.0).

- Reimplemented `DuckDBDataReader` for better performance.
- Added named parameter support.
- Added support for reading List types.

#### Bindings

- Added bindings for the Data Chunks API.

## 0.8.1

Released 2023-07-08 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.8.1), [changes since 0.8.0](https://github.com/Giorgi/DuckDB.NET/compare/9f1b2cf93326...e72e27150f95)). Built on DuckDB [v0.8.1](https://github.com/duckdb/duckdb/releases/tag/v0.8.1).

## 0.8.0

Released 2023-05-17 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.8.0), [changes since 0.7.1](https://github.com/Giorgi/DuckDB.NET/compare/5585dc529a9e...9f1b2cf93326)). Built on DuckDB [v0.8.0](https://github.com/duckdb/duckdb/releases/tag/v0.8.0).

- Added support for executing multiple statements at once.
- Added `DbProviderFactory` support.
- Fixed reading `DateTime` values.

#### Bindings

- Added bindings for the extract statements API.

## 0.7.1

Released 2023-03-04 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.7.1), [changes since 0.6.1](https://github.com/Giorgi/DuckDB.NET/compare/250f6a53f255...5585dc529a9e)). Built on DuckDB [v0.7.1](https://github.com/duckdb/duckdb/releases/tag/v0.7.1).

- Fixed a bug when inserting Unicode text through the appender.

## 0.6.1

Released 2023-01-08 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data.Full/0.6.1), [changes since 0.4.0.10](https://github.com/Giorgi/DuckDB.NET/compare/193effa95387...250f6a53f255)). Built on DuckDB [v0.6.1](https://github.com/duckdb/duckdb/releases/tag/v0.6.1). This is the first release with the `.Full` packages, which bundle the DuckDB native library.

- Added a managed implementation of the DuckDB appender.

## 0.4.0.10

Released 2022-09-03 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data/0.4.0.10), [changes since 0.4.0.1](https://github.com/Giorgi/DuckDB.NET/compare/8c16316eaf66...193effa95387)).

- Added support for parameterized queries, and for reading and writing all supported DuckDB types.

#### Bindings

- Added types for Interval, HugeInt, Blob and other native DuckDB types.

## 0.4.0.1

Released 2022-07-06 ([NuGet](https://www.nuget.org/packages/DuckDB.NET.Data/0.4.0.1), [changes since 0.4.0](https://github.com/Giorgi/DuckDB.NET/compare/bf61898633cd...8c16316eaf66)).
